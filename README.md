# 🎙️ Voice AI Chatbot

An interactive AI-powered chatbot that supports both **text and voice communication** using Google's Gemini AI. The chatbot can understand spoken input, generate intelligent responses, speak replies aloud, and maintain conversation logs with timestamps.

---

## ✨ Features

✅ Text Input via Keyboard  
✅ Voice Input via Microphone  
✅ Speech-to-Text (STT) Conversion  
✅ AI Responses using Gemini 2.5 Flash  
✅ Text-to-Speech (TTS) Output  
✅ Real-Time Conversation Interaction  
✅ Timestamped Conversation Logging  
✅ Easy-to-Use Console Interface  

---

## 🛠️ Technologies Used

- Python
- Google Gemini API
- SpeechRecognition
- PyAudio
- pyttsx3
- Datetime Module
